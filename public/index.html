🕵️ IP 信息
功能介绍
1、多个公开数据源交叉核验你的出口 IP 与归属地，结果不一致通常说明走了代理或 CDN。
2、IP 行按返回值自动标注 IPv4 或 IPv6，国家 / 地区 / 城市已合并为「地址」一行。
3、数据源未返回的字段会自动隐藏该行；真实反映你的出口 IP——不使用反代（反代会显示反代节点而非你的真实出口）。
